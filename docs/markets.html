making markets

open one

!market create "Question?" 20 30
the question in quotes, then the starting yes price, then minutes until trading stops. leave the numbers off for 50 and no time limit.
!market kalshi giants
search real Kalshi markets, then !market kalshi create to open the match. pasting a Kalshi link works too.

run it

!market resolve market2 yes
pays out a created market. yes or no.
!market close market2
stops trading now. resolve later.
!market void market2
cancels it. everyone gets their KWONKS back.

rules

  • one clear yes/no answer, and say when it gets decided
  • resolve as soon as the answer is in
  • bad question? void it, don't guess
